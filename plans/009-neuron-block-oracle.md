- `Sources/Slotstream/ExpertStore.swift` exposes `readBatchChecked`, returning nine tensors in the existing widened pool representation. `Sources/SlotstreamDiagnostics/Diagnostics+JANG.swift` already compares dequantized original projection values with this representation. Reuse this tested path; do not implement another6-bit unpacker or read full resident model weights.
- `Sources/Slotstream/Layers.swift` computes `hidden = silu(g) * u` in the pool path's local `project` function, then feeds it to the full down projection. Routed IDs and original router ranks are available here. Existing optional `FlashObservationSink` observes tensors; preserve that observer's meaning rather than making observation implicitly alter math.
- `Sources/Slotstream/Model.swift` installs the observer at each MoE and exposes checked persistent-state forwards. The native capture command warms each document with observation disabled, then runs each scored input separately with the same persistent state. Failure invalidates a partially advanced state; preserve that contract.
- `RuntimeAllocationPolicy` in `Plan.swift` already accepts explicitly reserved diagnostic bytes up to1GiB, and `JANGPlanning.swift` charges them before sizing the pool. Existing capture reserves128MiB. Extra oracle residency must be charged in addition; do not assume it fits inside that reservation.
